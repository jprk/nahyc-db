# Adresář /db

Tento adresář obsahuje databázové soubory a UML návrhy. Nachází se zde výsledný databázový soubor (`regulatory_documents.db`), UML designy, diagramy a Enterprise Architect projekt. Všechny pomocné a inicializační Python skripty (např. `init_db.py`) byly přesunuty do adresáře `/tools`. Dokument s popisem SQL struktury databáze (`DP004 Struktura SQL.docx`) byl přesunut do adresáře `/documents` (dříve `docs/`).
